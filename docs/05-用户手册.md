# 某专业师生业绩管理系统——用户手册

适用版本：1.0；日期：2026 年 10 月 17 日。初次运行方式见根目录 `README.md`；界面名称如有微调，以实际页面为准。

## 1. 登录与账号

打开系统地址，输入账号和密码。演示账号为管理员 `admin / Admin@12345`、教师 `teacher / Teacher@12345`、学生 `student / Student@12345`。这些账号只用于本地样例，部署账号由管理员创建。

个人修改密码需填写原密码，新密码至少 8 位并包含字母、数字。忘记密码联系管理员在用户管理中重设；不要通过删除数据库找回密码。

## 2. 查看成果

进入成果管理，按关键字、类型、级别、状态、年份、支撑指标和范围筛选。普通用户可见本人填报、参与或指导的记录；管理员可见全部。

“我的”范围包含本人拥有或作为作者/成员参与的成果，“指导”范围显示本人被标记为指导教师的成果。教师的指导成果来自同一条成果的指导关系，无需复制录入。

## 3. 填报与维护

1. 新建成果，填写名称、类型、级别、获得日期和说明。
2. 根据成果类型填写分类信息，如竞赛奖项、专利号或论文信息。
3. 添加共同参与人，选择作者、成员或指导教师角色并填写排序；指导教师需要教师账号。
4. 选择适用的认证支撑指标，保存为草稿。
5. 打开已保存成果，上传证书、证明或论文首页等材料。
6. 检查日期、人员、材料和支撑指标，提交审核。

共同成果由一名填报人建立一条记录，关联所有成员；避免每人各建一份。所有者会自动进入参与关系。参与者可以查看成果，但只有所有者或管理员能修改草稿/退回内容。

成果日期决定统计年度，应填写实际发生日期。专利申请和授权、论文录用和发表应在分类信息与说明中区分，并按专业规定统一录入政策。

## 4. 支撑材料

- 支持 PDF、PNG、JPEG，文件内容应与扩展名一致；其他格式请先转为上述格式。
- 单个文件不超过 20 MB，每项成果最多 50 个附件。
- 文件名不能包含路径、控制字符或非法片段。
- 在成果详情中查看材料列表并下载。首版以下载方式提供材料，未承诺 Word/PDF 专用在线预览。
- 草稿与退回状态下，所有者或管理员可上传和删除；待审及通过后材料锁定。

材料权限跟随成果。不要将系统附件链接当作公开分享链接发送给未授权人员。

## 5. 提交、退回与审核

草稿提交后进入待审。管理员查看内容和材料后通过或退回，退回需填写原因。填报人根据意见修改后再次提交，详情可查已有审核记录。

管理员不能审核自己拥有或参与的成果，包括被列为参与人或指导关系的情况；请由其他无关联管理员处理。待审和已通过记录不能直接修改或删除。首版不包含已通过成果变更申请和全文历史版本功能。

## 6. 数据总览

仪表盘正式统计仅计审核通过的成果。多人共同成果总数为 1 项；参与人次与成果总数含义不同。教师/学生人数为所统计成果涉及的去重人数。年份依据成果发生日期的自然年，普通用户图表仅统计其可见数据。

待审数反映当前待处理量，未计入正式成果总数。需要逐项核对时，可返回成果列表使用对应条件查询。

## 7. 支撑指标与导出

管理员先维护指标编码、名称和说明；填报时将成果与指标关联。可在列表按指标和年度等条件筛选，再导出：

- Excel：成果编号、名称、类型、日期、状态、人员、指标、分类详情、说明和附件数等台账。
- ZIP：成果清单 Excel、材料索引 CSV、使用说明，以及按成果类型和编号分类的附件。

导出受当前账号权限及筛选条件约束，默认只包含已通过成果；显式选择状态时按所选状态导出，应在对外使用前核对。单次最多导出 10000 项成果；ZIP 内附件合计不超过 100 MB，超限时缩小年度、类型或指标范围。

Excel/ZIP 是工作台账与材料包，不能替代数据库备份。

## 8. 管理员日常工作

在用户管理中新增师生账号，正确指定角色、学工号、年级与所属单位。停用离校或无须使用的账号；首版不提供用户物理删除。不能停用、降权或更改当前管理员自己的登录账号，以免误锁定当前操作。

定期检查待审队列、退回原因与重复录入，统一日期和成果级别口径。支撑指标与实际认证要求保持一致；指标关联是证据整理，不自动产生达成度评价。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| 看不到某条成果 | 核对是否为填报人、参与人或指导教师，以及是否启用了筛选 |
| 无法修改 | 核对是否为所有者/管理员，且状态为草稿或退回 |
| 无法审核自己的成果 | 使用无关联的另一管理员处理 |
| 上传被拒绝 | 检查实际格式、扩展名、大小、文件名和附件数量 |
| 统计比填报数少 | 正式统计只包含通过成果，且受年份和数据权限限制 |
| 刷新后需要登录 | 会话可能超时，重新登录后再操作 |
| 附件找不到 | 联系管理员核对数据库与材料是否成套恢复 |

退出前确认草稿已保存，通过页面退出登录。公共电脑使用完成后关闭页面。
