## 时间字段处理

当前 MySQL 表的时间戳精度为秒，原 H2 新增记录的 4 个时间字段包含小数秒。本次使用显式时间精度转换参数，将这 4 个字段截断到目标秒精度，保持界面显示的年月日时分秒一致。原始更高精度数值保存在迁移 JSON 审计记录与原 H2 备份中；不能把这一转换描述为纳秒精度完全保留。
